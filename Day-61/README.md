# Day 61 - SQL Transactions and ACID Properties

## Introduction
Today I learned about SQL transactions and ACID properties
using MySQL.

Transactions help maintain data consistency and reliability
when multiple database operations are performed.

## Topics Covered
- SQL Transactions
- START TRANSACTION
- COMMIT
- ROLLBACK
- SAVEPOINT
- ROLLBACK TO SAVEPOINT
- ACID Properties
- Atomicity
- Consistency
- Isolation
- Durability
- Transaction Management

## Database Used
ecommerce_db

## Tools
- MySQL 8.0+
- MySQL Workbench

## Learning Outcome
I learned how to manage database transactions and protect
data from incomplete or failed operations.
