
# Practice Tasks

## Task 1

Insert one employee record.

Command:

VALUES (1, 'Rahul', 'IT', 50000);

## Task 2

Insert three employee records using a single INSERT statement.

## Task 3

Insert an employee record by specifying selected columns.

Command:

INSERT INTO employees (id, name, department)
VALUES (4, 'Rohit', 'IT');

## Task 4

Insert five different employee records into the employees table.

## Task 5

Display all inserted records.

Command:

SELECT * FROM employees;
