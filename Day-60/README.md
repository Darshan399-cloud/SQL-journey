# Day 60 - SQL Triggers and Functions

## Introduction
Today I learned about SQL Triggers and User-Defined Functions
using my existing E-Commerce database.

## Topics Covered
- SQL Triggers
- BEFORE INSERT Trigger
- AFTER INSERT Trigger
- BEFORE UPDATE Trigger
- AFTER UPDATE Trigger
- BEFORE DELETE Trigger
- OLD and NEW Keywords
- User-Defined Functions
- CREATE FUNCTION
- RETURN Statement
- DROP TRIGGER
- DROP FUNCTION

## Database Used
ecommerce_db

## Tools
- MySQL 8.0+
- MySQL Workbench

## Learning Outcome
I learned how to automate database operations using triggers
and perform reusable calculations using SQL functions.
