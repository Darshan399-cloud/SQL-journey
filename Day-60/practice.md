# Day 60 - SQL Triggers and Functions Practice

## Trigger Practice

1. Create a BEFORE INSERT trigger to prevent negative product prices.
2. Create an AFTER INSERT trigger to record new customer details.
3. Create a BEFORE UPDATE trigger to prevent negative stock.
4. Create an AFTER UPDATE trigger to maintain product price history.
5. Create a BEFORE DELETE trigger to prevent deletion of ordered products.
6. Display all triggers in the database.
7. Drop an existing trigger.

## Function Practice

8. Create a function to calculate a 20% discount.
9. Create a function to calculate the total amount of an order.
10. Create a function to calculate GST.
11. Create a function to classify products as Expensive, Medium, or Affordable.
12. Create a function to calculate the final price after discount.
13. Create a function to calculate the average product price.
14. Use a function inside a SELECT statement.

## Advanced Questions
