# Practice Tasks

## Task 1

Create two tables named employees and customers.

## Task 2

Insert at least 5 records into each table.

## Task 3

Use UNION to combine names from both tables.

## Task 4

Use UNION ALL to combine names from both tables.

## Task 5

Observe the difference between UNION and UNION ALL.

## Task 6

Use UNION with a WHERE condition.

## Task 7

Use UNION ALL with a WHERE condition.

## Task 8

Try combining SELECT statements with different numbers of columns.

## Challenge

1. What is UNION?
2. What is UNION ALL?
3. What is the main difference between UNION and UNION ALL?
4. Does UNION remove duplicates?
5. Does UNION ALL remove duplicates?
6. What happens if two SELECT statements have different numbers of columns?
7. What is the purpose of UNION?
8. Which is generally faster: UNION or UNION ALL?
