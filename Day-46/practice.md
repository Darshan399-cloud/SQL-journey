# Practice Tasks

## Task 1

Create an employees table with employee ID, name, department and salary.

## Task 2

Insert at least 8 employees, including some employees with equal salaries.

## Task 3

Use ROW_NUMBER() to number employees by salary.

## Task 4

Use RANK() to rank employees by salary.

## Task 5

Use DENSE_RANK() to rank employees by salary.

## Task 6

Rank employees separately by department using PARTITION BY.

## Task 7

Calculate the average salary of each department using a Window Function.

## Task 8

Calculate a running salary total using SUM() OVER().

## Task 9

Use LAG() to display the previous employee's salary.

## Task 10

Use LEAD() to display the next employee's salary.
