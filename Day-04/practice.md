# Practice Tasks

## Task 1

Display all records from the employees table.

Command:

SELECT * FROM employees;

## Task 2

Display only the name and department columns.

## Task 3

Display id, name and salary columns.

## Task 4

Display unique department names.

Command:

SELECT DISTINCT department
FROM employees;

## Task 5

Display the name column with the alias employee_name.

Command:

SELECT name AS employee_name
FROM employees;

## Task 6

Display department with the alias dept.
