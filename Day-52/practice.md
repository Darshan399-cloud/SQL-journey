## Beginner

1. Find employees earning above the average salary.

3. Find the second-highest distinct salary.
4. Find the third-highest distinct salary.

## Intermediate

12. Find salary values that occur only once.

## Advanced

13. Find the top two distinct salary ranks in each department.
14. Explain the difference between RANK() and DENSE_RANK().
15. Explain the difference between a subquery and a CTE.
16. Explain the difference between EXISTS and IN.
17. Find the highest-paid employee in each department.
18. Find employees earning more than the company average.

## Challenge

Solve all questions using the employees and departments tables.
