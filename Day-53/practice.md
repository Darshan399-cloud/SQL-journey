# Day 53 - SQL Real-World Practice

## Beginner Questions

1. Find employees earning more than 40000.
2. Find employees whose names start with A.
3. Count all employees.
4. Find the maximum salary.
5. Calculate the average salary.

## Intermediate Questions

6. Find the second-highest distinct salary.
7. Find duplicate salary values.
8. Count employees in each department.
9. Find departments with more than two employees.
10. Display employee names with department names.
11. Find employees without a department.
12. Calculate department-wise total salary.

## Advanced Questions

13. Find employees earning above average salary.
14. Find employees earning above their department's average salary.
15. Find the highest-paid employee in each department.
16. Find departments without employees.
17. Rank employees by salary using DENSE_RANK().
18. Categorize employees using CASE.
19. Find the top three distinct salary values.
20. Use a CTE to find employees earning more than 50000.

## Challenge

Write all 20 queries without copying the examples.
Run them in MySQL and verify the results.
