# Day 51 - SQL Interview Practice

## Beginner Questions

1. Display all employees.
2. Find employees earning more than 50000.
3. Find employees earning less than 40000.
4. Find employees whose names start with A.
5. Find employees whose salary is between 40000 and 60000.
6. Count all employees.
7. Find the maximum and minimum salary.
8. Calculate the average salary.

## Intermediate Questions

9. Find the second-highest distinct salary.
10. Find the third-highest distinct salary.
11. Find duplicate salary values.
12. Find employees earning above average salary.
13. Count employees in each department.
14. Find departments with more than two employees.
15. Display employee names with department names.
16. Find employees who do not belong to a department.
17. Find departments that have no employees.
18. Calculate total salary for each department.

## Advanced Questions

19. Find all employees earning the highest salary.
20. Find the highest salary in each department.
21. Find the top two salary ranks in each department.
22. Rank all employees by salary using DENSE_RANK().
23. Find departments whose average salary exceeds 50000.
24. Find employees earning more than their department's average salary.
25. Explain the difference between WHERE and HAVING.
26. Explain the difference between INNER JOIN and LEFT JOIN.
27. Explain the difference between RANK() and DENSE_RANK().
28. Explain the difference between COUNT(*) and COUNT(department_id).
29. Find the second-highest distinct salary without using LIMIT.
30. Explain why GROUP BY is used with aggregate functions.
