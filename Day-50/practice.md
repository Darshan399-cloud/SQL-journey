# Day 50 - SQL Practice Questions

Use the employees and departments tables created in commands.md.

## Beginner Level

1. Display all employees.
2. Display only employee names and salaries.
3. Find employees earning more than 50000.
4. Find employees earning between 40000 and 60000.
5. Display employees in descending salary order.
6. Find employees whose names start with A.
7. Count the total number of employees.
8. Find the minimum and maximum salary.
9. Find employees whose department_id is NULL.
10. Display the top three highest salaries.

## Intermediate Level

13. Find departments with an average salary above 50000.
14. Find the second-highest distinct salary.
15. Find duplicate salary values.
16. Display employee names with department names.
17. Display all departments, including departments without employees.
18. Find employees earning more than the average salary.
19. Rank employees by salary.
20. Find the total salary for each department.

## Advanced Level

21. Find the third-highest distinct salary.
22. Find the highest-paid employee in each department.
23. Find employees earning the same salary.
24. Use a CTE to find employees earning more than 50000.
25. Use CASE to categorize employees by salary.
26. Use ROW_NUMBER() to number employees by salary.
