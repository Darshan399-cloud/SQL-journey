\# SQL Basics



SQL stands for Structured Query Language.



SQL is used to communicate with relational databases.



SQL can be used to:



\- Create databases

\- Create tables

\- Insert data

\- Retrieve data

\- Update data

\- Delete data

\- Manage database structures



\---



\## What is SQL?



SQL is a standard language used to store, retrieve, manipulate and manage data in relational databases.
