# Day 57 - SQL E-Commerce Database Project

## Introduction
Today I created a complete E-Commerce database project using MySQL.

This project helps me understand how an online shopping system stores and manages data.

## Topics Covered
- Database creation
- Table creation
- Primary Keys
- Foreign Keys
- Constraints
- INSERT statements
- SELECT statements
- JOIN operations
- Aggregate functions
- GROUP BY and HAVING
- Subqueries
- Real-world business queries

## Database Tables
1. customers
2. categories
3. products
4. orders
5. order_items
6. payments

## Project Features
- Store customer information
- Manage product categories
- Manage product stock and prices
- Store customer orders
- Manage order items
- Track payment details
- Generate sales reports

## Tools Used
- MySQL 8.0+
- MySQL Workbench

## Learning Outcome
I learned how to design and work with a multi-table E-Commerce database using SQL.
