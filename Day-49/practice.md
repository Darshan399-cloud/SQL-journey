# Day 49 - SQL JSON Functions Practice

## Practice Questions

1. Create an employees table with id and details JSON columns.

2. Insert three employees with name, age, and city in JSON format.

3. Display all employee records.

4. Extract the name of every employee using JSON_EXTRACT().

5. Extract the city using the ->> operator.

6. Find employees who live in Mumbai.

7. Update an employee's age using JSON_SET().

8. Add a department key using JSON_INSERT().

9. Replace an existing city using JSON_REPLACE().

10. Remove the age key using JSON_REMOVE().

11. Display all keys using JSON_KEYS().

12. Find the length of a JSON array using JSON_LENGTH().

13. Create a JSON object using JSON_OBJECT().

14. Create a JSON array using JSON_ARRAY().

15. Check whether a JSON array contains a value using JSON_CONTAINS().
